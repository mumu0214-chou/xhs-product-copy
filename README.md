# xhs-product-copy

依据已选参考、主题或母稿创作、改写和裂变小红书商品笔记的 Codex Skill。自带 `references/style-baseline.md`，保存从已认可方向整理的脱敏表达片段、转场分析与反例；单独安装即可读取，换设备不必先提供旧聊天。

本机共用台账中的完整认可稿和较新反馈可作为补充；这些个人历史资料不包含在本仓库中。具体产品、价格、规格和服务仍从当次任务读取，不由风格样例预设。只负责写作，不搜索或挑选对标；使用状态的自动回写尚未联调。

技能文件位于 `skills/xhs-product-copy`。安装时可请求 Codex 使用 `$skill-installer` 从本仓库安装该目录。私有仓库需要访问权限。
