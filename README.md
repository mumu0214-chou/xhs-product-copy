# xhs-product-copy

依据已选参考、主题或母稿创作、改写和裂变小红书商品笔记的 Codex Skill；只负责写作，不搜索或挑选对标。自带商家口吻参照，产品事实从当次任务读取。

共享台账 v2 已接通写作回写：读取查找技能的交接文件，逐批保存完整母稿和裂变、保留修改版本、续写追加编号，结束后核对任务进度。单独写作也能记录，不依赖另一个技能安装；没有对标的原创稿不会创建虚构来源。

同一批重试不重复计数，同一篇修订不增加独立使用次数，一篇母稿裂变十篇仍只算一次模板使用。明确反馈限定到具体稿件版本、选择或模板；生成、认可、发布分开记录，用户沉默不算认可。

两个技能各自携带同版台账程序，默认连接本机 `~/Documents/Codex/小红书笔记台账`；可用 `XHS_LEDGER_ROOT` 或 `--root` 指定共享位置。支持旧数据迁移、并发写入和手动导出。回写由技能执行阶段调用，不是后台监听；不包含跨设备自动同步。

技能文件位于 `skills/xhs-product-copy`。可请求 Codex 使用 `$skill-installer` 从本仓库安装该目录；私有仓库需要访问权限。运行依赖 Python 3.9+ 标准库，适用于 macOS/Linux。

`references/style-baseline.md` 随包提供口吻参照；本机完整认可稿可作为补充。个人台账、具体产品、来源全文和成稿不包含在本仓库中。

在技能目录运行 `python3 tests/test_ledger.py` 验证台账行为。操作接口见 `references/ledger.md`。两个技能中的 ledger.py、ledger.md 和测试应保持同版。
