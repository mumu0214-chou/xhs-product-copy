# 把已选原文迁移成目标产品文案

## 接收参考

使用用户已指定的参考，或 `xhs-note-finder` 交接的选中笔记。先读交接正文；若只有已选链接，可打开这篇补读。不得扩展搜索、重选行业或浏览推荐流。

判断阅读范围：正文已读才能分析正文；只有标题或封面时只借相应表达；视频只读到简介时，不声称读了口播。原文不可访问时，说明缺少什么，使用已有可读参考，或在用户授权原创的范围内创作。不要编造来源。

## 读原文时只抓真正影响改写的东西

- 第一句为什么值得继续看？
- 整篇在说哪件事，情绪来自哪里？
- 从话题转到产品的那句话在哪里？
- 最后如何让人愿意尝试，而不是突然喊口号？

把这个思路带到目标产品，句子重新写。只借结构与语气，不搬运原商品的功效、工艺、成本、销量、顾客经历和促销。

区分“话题相同”和“吸引点保留”。原文让人惊讶的是这个价能买到一整套，改稿只列套餐里有哪几样，就可能丢掉主要吸引力；应在当前事实支持的范围内保留对总量、价格或搭配的直观表达。原文让人馋的是一个具体动作，改稿反复说“好想吃”，也不算保留了它的表达方式。

不能照搬的竞品评价、原作者经历或促销事实可以舍弃，但不要连同商家的态度、接话和转折一起磨平。若吸引点完全依赖当前没有的事实，则按下方流程换用合适参考；不要悄悄另造“选购困难”等话题，仍声称保留了原结构。

若某个结构的成立依赖目标产品没有的事实，不硬造事实。可以使用交接中的其他合适备选，或说明这篇不适合并由查找技能另找；不在写作技能中自行开展新搜索。例如靠低价福利成立的笔记，不应给高价产品凭空加折扣；用材质剖面证明成分的逻辑，也不能自动移到无法凭外观验证的食品含量上。

## 输出

默认每篇：原文链接 → 一句话说明借的思路 → 改写标题 → 完整正文。分析保持简短，重点是成稿。只交文案、不要分析、指定表格等用户格式优先。

保持用户认可的口吻，尊重各篇已选原文不同的表达结构。避免所有行业的原文最后都被改成同一种“避坑科普＋固定卖点”文章。
