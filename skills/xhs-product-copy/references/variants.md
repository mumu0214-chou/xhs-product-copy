# 一篇母稿裂变成多篇

用户已明确认可：同一篇可以保持相同切入点，仅调整语气、段落、格式、信息顺序等，不必每一篇另造一个主题。

## 先锁定不变的部分

- 母稿主要在聊什么，以及它让买家愿意购买的理由。
- 当次商品事实与每篇必写信息。
- 用户已认可的商家口吻。

不为了差异化改变价格、成分、规格、认证或履约承诺。不要凭空换成不同的产品、不同优惠或不同经营历史。

母稿的事实准确、信息完整，不代表口吻已经通过。用户明确认可的母稿沿用；用户指出母稿生硬时，先校准再扩展。用户直接要求批量裂变时，在内部完成这个检查并继续交付，不额外设置“先批准一篇才能继续”的步骤，也不擅自缩减数量。

## 可调整的维度

每个版本挑两三项有意义的变化，无需展示内部规划表：

| 维度 | 可用变化 |
| --- | --- |
| 开头 | 直接说观点、提一个问题、提醒一句、引用一句角色对白、从场景开始 |
| 语气 | 着急、坦白、轻松吐槽、温和解释、自信介绍 |
| 信息顺序 | 先疑问后差异、先使用后产品、先观点后理由、先对话再解释 |
| 段落 | 短句留白、较长的聊天段落、两三句问答、少量引号或括号 |
| 讲解深度 | 简短点到、展开一处关键区别、用一个具体例子讲明白 |
| 结尾 | 邀请先试、提醒怎么挑、回应开头、给一种用法 |

形式可以相同，内容也可以重复，但不能十篇只是互换“姐妹/宝子”、增加感叹号或同义词替换。允许保持购买理由；不要求每篇制造一个新故事。

把同组稿放在一起检查中后段：如果只是换了两句场景开头，之后都按同样顺序贴上规格、价格赠品、物流和邀请购买，则重做部分版本的信息承接、接话方式或段落节奏。相同事实本来就应重复，变化应发生在如何把它们说出来；不要为变化编造新卖点，也不要用单纯增加标点代替变化。

## 数量与批次

- 用户指定多少，就交多少篇完整标题和正文；母稿不算进裂变篇数。
- 无数量且没有其他约定时，一篇母稿默认十篇。
- 多母稿用“母稿 01／版本 01”这类标识对应，防止内容混淆。
- 100 个账号只是可能的使用规模，不自动等于分配账号、创建身份、发布或安排互动。只有用户要求账号规划时才做对应工作。
- 大批量时仍须逐篇检查事实、必写项、价格位置和完整性；不要只给前几篇然后用“其余同上”代替。

## 同一话题的三种骨架

下面都是同一个“购买前看清差异”的话题。方括号是教学占位符，不是可以凭空补全的事实，也不是正式稿应原样出现的文本。

### A：直接提醒，短句多

**标题：买[商品]，这两句话记得问！！**

姐妹们别光问多少钱呀～

也问问[买家需要了解的问题一]，还有[问题二]！

同样叫[商品]，[真实差异]可不一定一样。

我们家[已确认的特点]，[已确认的价格]～[适用的履约信息]

喜欢[具体偏好]的姐妹，可以看看这款！！

### B：长段聊天

**标题：姐妹，买[商品]之前真的多问一句～**

看到便宜的想下单很正常，谁不想买得划算一点呀😂但买之前，还是建议看看[比较依据]。同样叫[商品]，[口语解释的真实差异]，所以不能光看名字和价格嘛～

我们家[产品事实]，[价格]。喜欢[具体特点或体验]的姐妹，可以试试！[已确认的履约信息]

买之前多了解一点，总比到手发现和自己想要的不一样好呀。

### C：允许角色创作时，用家人对白

**标题：我妈：你得说清楚，人家才知道怎么选呀！**

我说我们家[商品]挺好的呀～

我妈说：“好在哪儿？你得告诉人家嘛！”

行，这就跟姐妹们说清楚😂

我们家[产品事实]，[把差异讲成口语]。所以挑的时候，记得也看看[比较依据]～

[价格及已确认的履约信息]。喜欢[具体偏好]的姐妹可以试试！

这些骨架只展示差异，不要求每组固定包含三者，更不能把占位符一填就视为完成写作。
